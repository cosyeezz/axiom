# 子代理执行治理实施规范

状态：实现完成，全量回归通过（923 项，921 通过、2 跳过、0 失败）。本文是本次开发与验收依据；实现不得静默改变以下语义。

## 目标与边界

防止子任务与命令无限等待，保留部分成果，通过统一停止与交付促进主代理缩小任务粒度。会话、执行、工具调用分别管理。不得修改 pi 依赖源码、不得逐工具覆盖注册以实现单工具取消。保留主检出已有未提交文件。

## 统一停止协议

UI 手动停止、主代理 cancel_task、任务预算硬截止必须调用同一个停止机制，携带 source/reason/mode。默认 mode=summary：取消当前运行及在飞工具，等待停止后在原会话追加总结提示，禁止工具调用；最终仅通过既有 finalize/resultId/通知链路交付一次。不得先交付取消结果再另交付总结。mode=immediate 跳过模型总结但仍生成系统事实报告并交付。状态与报告始终保留停止事实，不因总结成功把原任务标成正常完成。

总结包含停止来源与理由、已有成果证据、未完成/未验证项、副作用/清理状态、简短归因与剩余任务拆分建议。不再调查或继续原任务。总结失败、超时、历史缺失时返回系统报告。停止未确认则明确记录，不假称已终止；不在旧执行尚运行时启动共享会话总结。

## 生命周期

终态会话允许 append 新追问并启动新执行，保留历史；运行中保留 steer/followUp。停止/总结期间显式追加的新要求排队，等当前执行的通知确认送达、清理确认后续接，不并行操作同一会话。停止前队列中未消费的指令保留但不擅自重启，需新的显式追加。每次执行具有标识，旧回调、结果、超时与通知不能污染新执行。保留任务链累计耗时；续接不自动重复原始任务。

## 时间预算

默认工作 600 秒、软收尾 180 秒；硬截止停止工作并进入统一总结交付。独立总结最多 60 秒，停止清理等待最多 10 秒，超时采用事实报告且标记未确认。外部计时器独立于模型轮次工作，重试、输出、运行中 append 不续期。软截止提示收尾且禁止扩展调查；硬截止必须发出取消。单次模型无响应也受约束。任务链累计耗时展示并在续接上下文反馈，不自动重试；延长预算必须明确配置。

## 命令超时

仅对已确认支持参数的 bash/powershell 在 tool_call 钩子处理：缺省 timeout 注入 180 秒；合法显式正数不改写；600 秒只是建议，不是工具级硬上限。主代理可显式 -1 表示不设工具时限（转为删除字段）；子代理禁止 -1、不限时及脱离管理的常驻进程。子任务总预算仍独立生效。非法参数不能静默修正。不要向 read/write/edit 等任意加字段；不覆盖 mcpScript 已有默认值。

记录有效超时与来源；结果中区分默认超时、显式超时、用户取消和一般失败。默认超时反馈说明未填参数所以使用 180 秒、建议合理显式设置（通常 <=600 秒）、长测试可设更长、重试前核实副作用。不自动重试。提前向主/子代理说明策略。

## UI

工具卡片显示调用耗时、有效超时及来源（默认/显式/不限时），结束固定时长。使用现有执行事件，不提供单工具停止按钮，不按无输出杀进程、不按输出续期。子任务展示执行耗时、预算与阶段；提供停止并总结/立即结束、可选理由。前端刷新不影响后台计时，重新连接从状态恢复。

## 主代理规则与通知

派发须单一可验证目标、明确范围/交付/停止条件；告知真实预算。收到停止结果通过原 read_result 读取并利用成果，告知未完成项，不原样重派、不擅自恢复用户停止的工作。范围过大、工具阻塞、环境问题区分处理。通知去重，绑定最终结果/执行。旧执行的结果凭证在续接后仍可读，未投递通知保存在 previousResults；SQLite 待通知索引使用全部执行的聚合状态，重启宁可幂等补投、不漏历史结果。
