# Axiom

多智能体协作的可靠基础。独立 Node.js 服务，通过 Pi SDK 运行主 Agent，以 `delegate` 并行启动子 Agent、以 `read_result` 读取结果，通过 WebSocket 输出实时事件。

## 启动

需要 Node.js >=22.5，以及已配置好凭据和所需扩展包的 Pi。未修改默认新会话配置时，主 Agent 和子 Agent 加载本机 Pi 已启用的 Skills、插件、MCP、提示词模板及目录上下文；基础编码工具为 read/bash/edit/write，主 Agent 额外获得 delegate/read_result/append 三个协作工具。默认能力与终端持久配置对齐，不继承另一终端进程的临时参数、会话状态或已执行的模式命令。纯 TUI 组件和终端快捷键不适用于网页；当前无插件交互 UI 桥，需要审批的 MCP 调用按适配器规则拒绝，不自动批准。

### 一键安装（macOS / Windows）

本仓库即 npm 包，两种路线任选；缺 Node 时安装脚本会经 Homebrew / winget 自动安装，随后装依赖、启动服务并在就绪后打开浏览器。交互终端逐项确认（默认注册登录自启、打开浏览器）；脚本调用可用 `--no-autostart` / `--no-browser` 关闭。自定义端口写项目根 `.env.local`（`AXIOM_PORT=…`），安装、自启、服务读取同一来源。

npm 路线（推荐）：

```sh
npm install -g github:cosyeezz/axiom
axiom-setup
```

git 路线（macOS 终端）：

```sh
git clone --depth 1 git@github.com:cosyeezz/axiom.git ~/axiom; sh ~/axiom/install.sh
```

Windows（PowerShell）：

```powershell
git clone --depth 1 git@github.com:cosyeezz/axiom.git "$env:USERPROFILE\axiom"; & "$env:USERPROFILE\axiom\install.ps1"
```

Windows 也可直接双击 `install.cmd`。更新版本：网页「服务 → 检查更新」（按 GitHub master 提交比对，内容变更即发现；npm 安装自动重装并重启；开发目录提示 git 拉取），或重跑安装命令。卸载自启：`npm run autostart:disable`。

### 维护：发布更新

公开仓库是 MyWorkbench 内 `axiom/` 的镜像（git subtree）。改动合并到 MyWorkbench master 后需手动同步镜像，同步后各安装实例的「检查更新」即可发现并自动升级（按提交比对，内容变更即发现）。发布时顺手把 `axiom/package.json` 的 `version` 升一档——页面服务菜单会显示当前版本，便于确认更新生效（检测本身不依赖它）：

```sh
git subtree push --prefix=axiom git@github.com:cosyeezz/axiom.git master
```

### 手动启动

```powershell
npm ci --ignore-scripts
$env:AXIOM_CWD = 'F:/your-project'
# 可选；默认使用 Pi 设置中的已认证模型，不可用时选择首个已认证模型
$env:AXIOM_MODEL = 'provider/model'
# 可选，默认 4319
$env:AXIOM_PORT = '4319'
npm start
```

### 自动启动与服务控制

跨平台当前用户登录后自动启动（无需管理员；默认不是登录前的系统服务）：

| 平台 | 系统原生方式 |
|---|---|
| Windows | 当前用户启动文件夹，隐藏窗口 |
| macOS | `~/Library/LaunchAgents`，LaunchAgent |
| Linux | `~/.config/systemd/user`，systemd 用户服务（需可用的用户服务管理器） |

以下命令仅注册/取消注册，不启动或停止当前进程，下次登录生效。Linux 如需未登录即运行，可由用户另行配置 `loginctl enable-linger`；脚本不会自行提升权限。

```powershell
npm run autostart:enable
# 取消自动启动
npm run autostart:disable
```

右上角独立显示「已连接 / 连接断开 / 正在重启」，与当前任务是否运行分开；「服务」菜单中的两种重启均使用统一暗色确认弹窗，说明连接中断与安装耗时，默认聚焦取消，支持 Esc 关闭；仅确认后发送重启请求。「服务」菜单提供：

| 操作 | 行为 |
|---|---|
| 快速重启 | 保存会话、停止服务并重新启动，不安装依赖 |
| 重建重启 | 停止服务 → `npm ci` 安装锁定版本 → `npm run build --if-present` → 启动 |
| 检查更新 | 按 GitHub master 提交比对（内容变更即发现）：npm 安装自动重装并重启；开发目录提示 git 拉取；已是最新不重启 |

Axiom 使用原生 JavaScript，目前没有编译脚本，因此重建时不会假装执行编译。安装可能访问网络并执行依赖安装脚本；失败信息会记录到日志并反馈到菜单。安装前暂存原依赖目录，安装/构建失败会恢复原依赖并尝试重新启动；构建脚本自身修改的产物不自动回滚。重启不拉取 Git 更新、不改变锁文件，也不删除会话历史。运行中的会话会阻止重启，请先停止任务；页面保留草稿并自动重连。

`npm start` 使用独立守护进程。直接 `node src/main.js` 仍可使用聊天，但不能从网页重启。首次从旧的直接启动迁移时，先停止旧进程，避免端口冲突。自动启动和安装输出日志位于 `~/.axiom/service.log`。守护进程自动读取项目的 `.env.local`（不提交），并保留 Node 所在目录到 PATH。移动项目或升级 Node 路径后需重新执行注册命令。

服务仅监听 `127.0.0.1`。健康检查 `GET /health`，WebSocket `/ws`。无需令牌。本机网页自动连接，服务校验 Host 和浏览器 Origin，拒绝其他网站跨站连接。本机进程可直接访问。不要公开部署到网络。工作目录不是沙箱，Agent 可以执行命令和修改文件。

## 会话已完成

- 列表分三类：按时间分组（今天/昨天/更早）、待处理（运行中的会话，紧挨在已完成上方）、已完成（收起区）。在同一类内拖动会话到另一行可手动排序，顺序保存在当前浏览器 localStorage，刷新保留；跨浏览器不同步。
- 将会话拖到列表下方的「已完成」区域即可收起；该区域紧贴会话列表，会话多时列表自动压缩滚动。默认折叠，展开后最多占侧栏 35%，不显示数量。列表顶部显示「待处理」分组。
- 点击编辑按钮前的对钩「完成并隐藏」也可隐藏（适合触屏/键盘；仅作为整理标记，不改变任务执行状态）；展开后点击向上箭头或拖回正常列表即可恢复。搜索同时筛选两个列表。
- 隐藏只整理列表，不删除记录、不停止任务，也不切换当前对话。状态保存在当前浏览器的 localStorage，刷新保留，不跨浏览器同步；清除网站数据会重置。

## 新会话与能力选择

- 「新会话」直接使用「设置 → 默认新会话设置」中保存的配置；首次自动创建、打开空工作空间、删除最后一个会话后的补建也统一使用它。初始仍为主/子代理全部能力。
- 默认配置可分别设置主/子代理供应商、模型，以及 Skills、MCP 服务、插件的全部或自定义选择（可全部取消）。保存仅影响之后创建的普通会话，不修改当前/已有会话，也不启动代理。选择即通过 WebSocket 自动保存，写入 `~/.axiom/defaults.json`，服务重启保留，不修改 Pi 的 settings/MCP 文件。默认能力预览实时跟随选择，状态提示区区分保存中、成功和失败；失败不覆盖旧配置。
- 「自定义新会话…」行为不变：沿用当前会话的主/子模型、能力初始仍为全部，忽略上面的默认配置；只为本次创建单独选择。两种入口复用同一弹窗、模型/能力选择器及服务端校验，不复制组件或另建配置框架。模型单选，能力通过折叠下拉中的复选框多选。
- 默认主模型可选固定模型，或「默认主代理模型」（沿用最近成功调整的主模型，尚未调整时用启动模型）；主/子代理均可设置思考等级，选项来自模型支持的等级；主代理留空沿用默认值，子代理留空跟随主代理，运行时按模型支持调整。子代理的模型与能力可分别选择「跟随主代理」，能力跟随实际主代理选择而非全部能力。默认能力清单按当前工作空间读取，不保存工作目录或目录信任；其他目录缺少所选能力时拒绝创建，不自动扩大为全部，编辑时保留并标出不可用项以便取消。
- 能力清单来自 Pi 原生包解析与 Skill 发现；仅列出本机已安装且已启用的资源，不安装新包。MCP 复用已安装 `pi-mcp-adapter` 的配置合并及 `createMcpAdapter({config})`，适配器本身不再重复显示为插件。每个代理拥有独立服务清单，未选服务不会通过该适配器暴露，stdio 服务默认使用会话工作目录。
- 未信任目录默认只加载全局能力并显示提示；在自定义弹窗确认信任后加载项目资源，仅本会话生效，不写入全局 trust/settings/MCP 文件。设置采用内存快照，保留全局和项目相对路径语义。
- 能力在创建时确定，设置弹窗显示主/子代理的能力摘要；模型支持执行中调整，下一次模型请求生效。未配置时子代理默认全部能力、模型跟随主代理；普通会话使用保存的默认配置，自定义会话可分别选择。状态通过会话文件恢复，服务重启不自动续跑。
- 插件加载失败会阻止创建并显示错误；启动钩子错误保留为加载提示。插件的启动和关闭事件均执行。插件命令可以没有模型回答，不会再误报失败。所有扩展仍有本机执行权限，取消勾选不是文件系统沙箱；选中的插件也可能贡献自己的额外工具。

协议新增 `capabilities.list({cwd?,trustProject?})`，返回不含凭据的 Skills/插件/MCP 目录与信任状态。`session.create` 新增 `model`、`thinking`、`subagentModel`、`capabilities`、`subagentCapabilities`、`trustProject`。能力值为 `null`（全部）或 `{skills:[id],mcp:[id],plugins:[id]}`，空数组表示不加载该类。主/子选择都在创建前校验，未知 ID 拒绝。`config.activeTools` 返回实际工具名用于验证。

`session.defaults.get` 返回 `{model,subagentModel,thinking,subagentThinking,capabilities,subagentCapabilities}`；`session.defaults.configure` 接收上述可选字段及 `cwd?`（仅用于校验目录里的可用能力），省略字段保留原值，保存失败保留全部旧值。主模型 `null` 使用最近主模型/启动模型，子模型 `null` 跟随主代理；`thinking:null` 沿用最近/启动思考等级，`subagentThinking:null` 跟随主代理；`subagentCapabilities:"inherit"` 跟随主代理能力，`null` 仍表示全部能力；默认配置不接收 `trustProject`。`session.create` 的显式字段优先于默认值，`useDefaults:false` 完全绕过这份默认配置，网页自定义入口使用该标记；最近主模型和思考程度的原有继承规则不变。

## 图片上传与放大预览

输入区支持点击图片按钮上传，或在输入框粘贴系统截图（Windows 可用 `Win + Shift + S`）；不再提供浏览器截图按钮或屏幕共享。待发送附件、消息和历史中的图片均可点击放大，也可通过 Tab 聚焦后按 Enter / 空格打开；点击关闭按钮、遮罩空白处或按 Esc 关闭预览。

```text
上传 / 粘贴 -> 光标处 [image1] + 同编号附件预览 -> Send -> 文字标记 + 消息图片
```

- 上传或粘贴时立即在光标处插入 `[image1]`、`[image2]` 占位（有选中文字时替换选区），可以继续在图片前后写说明；读取失败恢复原选区。缩略图显示同编号，点击 × 移除附件时同步删除对应标记并重排编号。手动删掉文字标记不会删除附件，删除图片请点 ×。
- 发送时保留占位，不再追加图片编号说明。模型请求会在 `[imageN]` 首次出现的位置紧接对应真实图片，保留前后文字顺序；重复引用不重复发图，未引用附件带编号放末尾，无效编号保留原文。普通发送、Steer / Follow-up 和恢复历史共用该转换；草稿、历史存储和撤回仍保留原附件顺序，多条撤回合并时同步调整编号。旧消息已保存的说明不回溯删除。
- 支持 PNG、JPEG、GIF、WebP，每条最多 4 张、每张最多 5 MiB；不支持 SVG，也不自动压缩或裁剪。大截图可先裁剪再粘贴。
- 可以只发图片，也可以搭配文字、Skill 和文件引用；附件跟随会话草稿，切换会话不会串图，发送失败保留附件。未发送草稿只存在当前页面内存，刷新页面会丢失。
- 运行中也可用 Steer / Follow-up 发送图片，队列显示附件数量，Esc 撤回时恢复图片；多条队列撤回后若累计超过 4 张，请移除多余附件后分批发送。
- 已发送图片在消息与历史中显示，随 Pi 会话记录保存。图片会发送给当前模型服务商，请避免包含密码等敏感信息；不支持图片的模型会明确拒绝，请换用视觉模型。
- `prompt` 支持可选 `images: [{type:"image", mimeType:"image/png", data:"原始 base64（不含 data: 前缀）"}]`。图片数、大小、类型、base64 与文件签名在服务端校验；仅有图片时 `text` 可为空字符串。

## 后台自动压缩

在默认新会话设置或自定义新会话中配置后台压缩，不再提供当前会话的独立压缩设置。修改默认压缩配置后，新会话直接使用；已有会话在服务重启后统一使用最新默认压缩配置（覆盖原来的会话压缩值），其他会话配置不变。初始关闭；开启后可设置 token 阈值（默认 100000）和上下文窗口占比（默认 70%），**任一先达到即触发**。留空表示不使用该阈值，开启时至少填写一个。占比使用当前主模型窗口，统计为当前上下文估算，不是会话累计消耗。近期保留量默认 20000 token，按安全消息边界保留，不拆散工具调用与结果。

可单独选择压缩模型（留空跟随主模型）和模型支持的思考等级。摘要由独立内存 Pi 会话生成，不出现在子任务列表；固定禁用全部工具、MCP、插件、Skills 和项目上下文，只接收摘要指令、上次摘要和历史快照，不执行历史中的指令。

```text
完整 turn 结束 -> 达到任一阈值 -> 固定快照 -> 后台生成摘要
主会话继续输出/执行工具 -------------------> 摘要待应用
下一次模型请求前 -> 校验检查点 -> 摘要 + 近期消息 + 全部新增消息
成功提交 -> 对应历史折叠为一个摘要块，展开查看摘要
```

每会话最多一个后台摘要任务；任务完成不立即修改运行中的上下文。应用时使用 Pi `prepareNextTurnWithContext` 安全入口，并保留其原生轮次刷新；用户排队输入仍由原队列投递。摘要过期、失败或取消时不删除原历史。接近模型窗口硬上限仍以 Pi 原生压缩兜底，必要时会等待，并非任何情况下都零延迟。摘要是有损的，也可能影响模型缓存命中率。

每次成功压缩保存独立记录，前端只隐藏本次覆盖的历史，保留近期和后台期间新增消息，不重建整个会话或清空输入。重连/重启恢复已保存摘要，未完成的后台摘要不会恢复；Pi JSONL 仍保留原文。

协议：`session.create`、`session.configure`、`session.defaults.configure` 支持 `compaction: {enabled,tokenThreshold,percentThreshold,model,thinking,keepRecentTokens}`，两个阈值和 model 可为 `null`。配置返回实际 compaction；快照包含 `compactions`，消息记录包含 `entryId`。成功事件 `agent.compaction` 包含摘要 ID、正文、保留边界和 `compactedMessageIds`，客户端按消息 ID 折叠而非按时间猜测。未启用此功能时仍保留 Pi 原生窗口保护。

## 会话与子代理运行信息

- 发送按钮显示 `Send`，不带上箭头。底部操作行上方显示运行摘要：缓存命中、上下文用量/窗口及占比、当前实际供应商 · 模型 · 等级，例如 `zai-coding-cn · glm-5.3-flash · max`，不加「思考」前缀。主/子模型等级选项也直接显示 `off/high/max` 等实际值，保留无障碍标签。桌面一行排列，窄屏自动换行。
- 缓存命中按最近一次模型回答的 `cacheRead / (input + cacheRead + cacheWrite)` 计算，并显示命中 token 数；没有用量或输入总量为零时显示「暂无数据」，不伪造 0%。上下文直接使用 Pi `getContextUsage()` 的当前估算，不是累计 token 消耗；压缩后尚无可靠统计时显示「待更新」。
- 主会话用柔紫色底、左侧色条和描边 `SUBAGENT` 标识突出子任务卡片，显示状态和简短标题；点击打开独立原生浮层，不在对话中堆叠详情，也不因新任务自动弹出抢焦点。浮层以右侧会话内容区居中、宽度保留 880px 上限，位置和遮罩避开左侧配置栏与顶部会话标题；侧栏收起、窗口缩放和手机布局同步适配。
- 浮层顶部固定显示缓存、上下文、供应商/模型/等级及「回到最上」「回到最下」按钮，仅下方任务说明、系统提示词、失败原因和消息滚动。回到最上暂停跟随，回到最下恢复跟随新输出；手动向上阅读不被刷新拉回底部。支持关闭按钮、点击会话区遮罩、Esc 和焦点返回，不会停止运行中的主/子代理。
- 子代理消息直接复用主会话的 `card/renderMessage`、`stream-renderer.js` 和 `markdown.js`，包含流式正文、思考折叠、代码块、表格、历史及最终消息，安全边界不变。系统提示词取自该子代理实际运行状态（含扩展动态修改），仅按纯文本展示；尚未创建代理时提示未加载。切换/重连时清理旧浮层，再按会话快照恢复。
- 主/子运行信息通过 `agent.runtime` 事件更新，只在消息、轮次结束及上下文压缩等边界采样，不随每个 token 重发。会话快照新增 `runtime`，子任务 `task.state` 与快照附带各自的 `runtime`，包含 `model/thinking/systemPrompt/context/usage`；子代理销毁前保留最终状态，切换或重连恢复，互不串用。`read_result` 与 `tasks.read` 仍只返回任务结果，不把展示用的系统提示词再塞入主代理上下文。

## 消息执行过程

- 等待模型响应显示 `connecting...`，思考中显示 `thinking...`、完成后为 `thinking`，准备工具调用显示 `calling...`；思考只保留一条入口，右侧「查看 / 收起」。活动行采用 12px 常规字重、16px 线条 SVG 与 24px 底座。连续没有正文、没有工具调用的思考合并展示，不堆叠空白 AXIOM 卡片和重复模型用量。
- 工具行按「语义图标 → 工具原名 → 操作对象 → 状态 → 详情」排列，直接显示 `read`、`edit`、`bash`、`powershell` 等，不加中文动作前缀；仅省略已知的 `functions.` 命名空间，悬停可看完整名称，未知工具保留原名。文件、命令、搜索等各有固定 SVG，完成后不替换成小对勾；工作空间内路径显示相对路径，长摘要省略，悬停保留完整值。手机将对象移到第二行。
- 思考、工具、Skill、重试、压缩记录及子代理系统提示词隐藏默认展开三角，使用「查看 / 详情 / 收起」提示，仍保留原生 details 的 Enter / 空格操作与焦点提示。展开后标题栏随会话滚动吸顶，右侧「收起」带向上收拢图标，读到中间也能折叠；工具输出、diff 和系统提示词不再限制内部高度，不产生第二层纵向滚动。
- 思考中使用灯泡外旋转环，连接中/准备调用使用高低亮度分段的 CSS 旋转环，工具执行中保留独立状态转圈；子代理启动中/运行中的卡片、浮层标题与输入区摘要均有清晰转圈。结束后停止，系统开启「减少动态效果」时静止但仍保留状态文字。
- 工具按用途分色：读取/搜索为雾蓝，命令为青绿，编辑/写入为暖金，思考/子代理为柔紫；失败仍用柔红。颜色仅作辅助，动作与状态文字始终保留。
- 点击或键盘展开工具详情：edit 优先显示工具返回的实际红绿 diff，没有 diff 时明确标注为请求改动。默认窄屏使用统一视图、宽屏使用左右对比；支持手动切换并在浏览器记住选择，窄屏始终回退统一视图；write 显示写入内容（无法仅凭参数判断新建或覆盖）；bash/read 等显示参数和文本输出。内容以纯文本安全展示，展开后才生成详情，每节最多显示 60,000 字符，超限提示独立放在该节下方，左右对比、统一视图和手机端均可见；完整结果保留在原会话记录中。
- 主会话、子代理及历史恢复使用同一套展示；只改变显示，不删除原始消息或修改模型上下文。

## 输出渲染与性能

正文与展开的思考共用 marked + DOMPurify 安全 Markdown 渲染，支持标题、强调、列表、引用、表格与代码。正文与思考均为 14px；正文灰白、重点暖金、补充说明柔紫、行内代码青绿、链接雾蓝。思考按斜体、正常字重展示（标题、`**强调**` 和表头也不加粗，保留 Markdown 语义）；代码和复制栏保持正体，便于辨认字符。代码块显示语言与「复制」，失败会提示手动选择复制；宽表格和代码仅保留必要的横向滚动，可用 Tab 聚焦，不限制纵向高度。复制控件在净化后生成，不允许 Markdown 注入按钮、脚本或 inline style。

流式更新只处理发生变化的消息，每帧合并一次；思考不触发正文 Markdown 重绘，折叠思考不解析 Markdown，展开才渲染。未打开浮层的子任务仅收集文本，不调度正文动画帧、不解析 Markdown，打开时一次显示完整结果（包括历史恢复与最终消息）；关闭再打开复用原有消息 DOM，不复制一套渲染逻辑。Markdown 按块比较，保留未变化的 DOM，仅对变化块解析、清理并替换；仍完整词法分析以正确处理后出现的引用定义。超长单个段落/代码块仍需重算该块，不保证恒定开销。

自动滚动请求合并，切换会话清理待绘制任务；删除重复任务恢复、单连接多订阅容器和重命名时的整份历史复制。静态资源启动时读取并生成 ETag，浏览器刷新时重新校验，未变化返回 304，不重复传输正文；更新静态文件后需重启服务。`public/stream-renderer.js` 独立负责渲染调度，`markdown.js` 负责安全块渲染。

视觉回归：先运行 `node tests/conversation-preview.mjs`，再用已有 Python Playwright + Chromium 环境执行 `python tests/conversation-ui.py [截图输出目录]`。测试使用静态样例，不读取用户数据、不调用模型；覆盖 1440/390/320px 配色、工具原名、活动行字号/字重/图标比例、行高与手机点击区域、Skill 键盘展开和模块强调、真实转圈/减少动态效果、长内容吸顶收起、无内部纵向滚动与子代理定位。

运行 `node tests/benchmark.js` 可复现 CPU/DOM 微基准。浏览器同机 3 个约 4KB 输出区 × 60 次更新，三次中位数从 391ms 降至 148ms（约 -62%）。这不是模型生成速度或真实端到端延迟指标。新增折叠任务场景：3 个任务 × 60 次更新，展开时 60 帧 / 180 次 Markdown 解析，折叠时 0 帧 / 0 次解析；完整内容保留，展开后按需呈现。

## 布局

会话消息区和底部输入区左右各留白 5%，不再限制为 880px 宽；桌面、侧栏收起及手机端均按可用会话区域宽度自适应。工具/思考行桌面最小高度 36px，手机点击区域至少 44px；消息间隔 24px、角色标题到正文 8px，正文仍保留 14px 与 1.8 行高。通过减少外围空白提高密度，不压缩正文行距；子任务详情浮层尺寸不变。

左侧固定工作空间和会话列表，提供搜索、今天/昨天/更早分组、最近活动排序、重命名和删除。侧栏可收起；手机端覆盖主区而非挤压内容，点击遮罩或 Esc 关闭，打开时主区不可交互。主区只滚动消息，输入区常驻底部；运行时显示插话、追加与停止按钮，空白输入与断线时禁用发送。切换会话保留页面内草稿、输入框高度和滚动位置，浏览器记住上次选择的会话 ID。页面内断线保留可阅读的消息与可编辑草稿，点击「重新连接」后恢复；刷新页面仍不保存草稿。子任务通过卡片打开详情浮层；历史恢复时按首条子任务消息的位置放回卡片，不再全部堆到用户请求之前。空会话显示简短欢迎内容。

会话存于 `~/.axiom/workspaces/<规范目录路径的 SHA-256>/`：Pi 原生 JSONL 保存模型上下文，每会话 JSON 保存标题、配置和网页历史/子任务快照。选择文件而非 SQLite，是因为 Pi 已提供 JSONL 的上下文恢复和压缩记录，无需增加数据库依赖、格式转换和迁移。左侧只显示当前工作空间；重命名与删除采用统一暗色原生弹窗，删除会停止任务并删除本地记录。启动恢复历史，不自动重新执行未完成的任务。

## 输入框加载 Skill

- 输入框开头键入 `/` 可按名称或说明补全当前会话 Skill（兼容 `/skill:名称`）；在正文空白后键入 `@` 可补全工作空间文件和文件夹。
- `@src/` 按目录浏览、继续输入筛选名称；含空格路径可用 `@"my folder/`。上下箭头选候选，Enter / Tab 添加标签，Esc 关闭而不撤回队列；文件夹可直接添加，或用右箭头 /「进入 ›」继续浏览。鼠标点击同样可选。
- 选中后复用原上下文标签与发送逻辑，文件或文件夹标签也可单独发送；只发送路径引用，不预读文件、不递归扫描目录、不增加依赖。

添加菜单采用 176px 宽的三行单行布局，说明收进悬停提示；加号为 28px 无边框细线 SVG 按钮，触屏扩大触控区域。输入区按「任务正文 → 模型选择/发送按钮 → 会话信息」排列，不再用 CSS order 重排。

输入框上沿「＋」菜单提供 Skill、工作空间文件、工作空间文件夹三个入口，使用统一线条 SVG 图标。搜索列表展示技能说明；文件/文件夹按层级浏览，过滤 `.git`、`node_modules` 与符号链接，服务端 realpath 校验禁止浏览工作空间外目录。选择后显示可移除标签，不改变原模型选择与运行信息布局。Skill 只显示在上方标签，输入框仅显示任务正文，发送时自动附加 `/skill:名称 `；手动输入有效 Skill 命令并键入空格后也转为标签，每次显式加载一个；文件/文件夹以路径引用随消息发送，由代理按需读取，不上传或递归灌入整目录。标签随页面内草稿切换保留，发送成功清空，失败保留。

会话里的原生 `<skill>` 消息块显示为默认折叠的 `SKILL` 描边标识和技能名，用雾蓝左侧色条、浅底色和边框与普通工具行区分；点击展开路径和经过 Markdown 安全渲染的正文，skill 块放在对应用户消息前面，与用户气泡平级，不嵌套；纯 skill 消息不显示空气泡，历史恢复也适用。该标识表示技能正文进入消息，不表示模型已完成执行。

### 统一文件 / 文件夹选择器

「打开工作空间」和「＋ → 文件 / 文件夹」共用 `public/file-picker.js` 原生网页弹窗，与现有主题保持一致，不再启动 PowerShell。支持地址输入、面包屑、上一级、刷新、常用位置、当前目录搜索和确认/取消；目录单击进入，文件选中后确认或双击添加。支持 Tab、上下箭头和 Esc，窄屏自动收拢位置栏。代码、配置、文档、图片、音视频、压缩包、PDF、字体和项目目录使用本地分类 SVG 图标，不加载远程图标或字体。

```text
打开工作空间 ─┐                    ┌─ 主机目录（绝对路径）
选择文件 ─────┼─ 共享选择器 ────────┤
选择文件夹 ───┘                    └─ 当前工作空间（限制范围）
                         点进目录 → 只读取该层 → 每页 200 项
```

- 只读取当前层名称和类型，不扫描子目录、不读取文件内容/大小/修改时间；搜索仅查当前目录，服务端先过滤再分页，按需「加载更多」。单层目录仍需 `readdir` 后排序，极端大目录若成为瓶颈再改为流式目录游标，不提前搭建索引服务。
- Windows、macOS、Linux 共用 Node 文件系统实现；主机模式提供用户主目录、文件系统根目录及 Windows 可用盘符，地址栏可输入 UNC 路径。浏览的是 **Axiom 服务所在机器**，不是另一台浏览器设备。系统权限错误在弹窗中提示并可重试。
- 工作空间引用保留相对路径和 `realpath` 边界校验，过滤 `.git`、`node_modules` 与符号链接；打开工作空间允许浏览本机目录但不预先加载其中的项目能力。选定后仍沿用已有会话切换/创建与信任流程；取消不切换。过期响应、会话切换和关闭弹窗不会覆盖新选择。
- 图片上传仍使用浏览器原生文件上传和粘贴：这是上传附件，不是引用服务端路径，不能混用两者。
- 新增 `files.browse({sessionId?,path?,directoriesOnly?,offset?,query?})`，返回 `path/parent/entries/nextOffset/breadcrumbs/locations`；省略 sessionId 为主机模式。旧 `workspace.browse({sessionId,path?})` 保留给输入补全并复用后端浏览逻辑，删除 Windows 专用 `workspace.pick`。沿用本地 WS Host/Origin 校验，不接受任意系统命令。`workspace.reveal({sessionId})` 使用 Explorer / open / xdg-open 打开系统文件管理器，Linux 需安装 xdg-open 并有桌面环境。

调研参考：[VS Code Lists And Trees](https://github.com/microsoft/vscode/wiki/Lists-And-Trees)、[Seti 文件图标主题](https://github.com/jesseweed/seti-ui)、[原生 JS FileExplorer](https://github.com/cubiclesoft/js-fileexplorer)。借鉴目录懒加载、文件分类和导航布局，不引入完整文件管理器或复制其图标资产；图标为本地自绘 SVG。[showDirectoryPicker](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker) 浏览器支持有限，也不能提供服务端工作目录路径，因此不作为跨平台实现基础。

普通发送、插话和追加均复用 Pi 原生 Skill 命令展开，在发送/入队时读取 Skill 正文，不另建文件读取接口，不修改会话能力配置。选择表示「本次发送要加载」，不代表模型已经使用；已进入上下文的 Skill 不会因取消下一次选择而被删除。会话配置新增 `skills: [{name, description}]`，取自主代理实际资源加载器。

## 队列与执行中交互

- 执行中显示 `Steer` / `Follow-up`：Steer 在下一个可介入节点补充指令，不立即中断运行中的工具；Follow-up 等当前这一轮结束后发送，不影响当前执行，也不保证上一轮成功。Enter 使用设置中的默认类型，初始为 Steer；配置页直接展示两者说明，下拉框复用模型选择样式。
- 输入框上方显示 Pi 原生队列和类型。点击队列或单按 Esc，使用 Pi `clearQueue()` 一次撤回全部队列并追加到现有草稿，不覆盖草稿；重新发送时可选类型。这里与 Pi 原生一致，不提供逐条删除。
- 双按 Esc（300ms 内）或「停止」取消执行。右上角已连接时显示 `Idle` / `Running`，断线为灰色。
- `prompt` 可带 `queueType: "steer" | "followUp"`；`session.configure` 可保存默认 `queueType`；`queue.withdraw` 返回 `{steering,followUp}`；`session.queue` 同步队列，attach 快照包含 `queue`。

## 协议

每个命令必须有请求 `id`；响应为 `{type:'response', id, ok, data?, error?}`。

```javascript
const ws = new WebSocket('ws://127.0.0.1:4319/ws', ['axiom']);
ws.onmessage = ({ data }) => console.log(JSON.parse(data));
ws.onopen = () => ws.send(JSON.stringify({id:'1', type:'session.create'}));
// 从响应 data.sessionId 取得会话 ID 后发送：
// {id:'2', type:'prompt', sessionId, text:'并行检查两个模块，读取结果并总结'}
// {id:'3', type:'session.attach', sessionId}  // 重连，返回快照并订阅
// {id:'4', type:'tasks.read', sessionId, taskId:'...', resultId:'通知中的 UUID'}
// {id:'5', type:'cancel', sessionId}          // 取消主 Agent 与当前子任务
// {id:'6', type:'session.close', sessionId}   // 释放会话与结果
```

`session.create` 自动订阅；断开连接不取消任务。重新 attach 返回状态、历史消息、当前流式消息、工具状态、任务结果与序号。快照后按事件 seq 接续，不要重复追加快照之前的内容。服务不保存每个增量的回放日志。

事件包含 `sessionId`、`seq`；Agent 事件包含 `agentId`，子任务另有 `taskId`、`parentAgentId`。类型为 `session.state`、`agent.message.start/end`、`agent.delta`、`agent.runtime`、`tool.state`、`task.state`、`error`。`agent.delta.data` 的 `type/contentIndex/delta` 对应内容块增量；thinking 是否可见取决于模型。`tool.state.data.partialResult` 为累计结果，替换展示而非追加。`agent.message.end` 的完整消息为最终事实。

主 Agent idle 不代表所有子任务完成，使用 task.state 判断子任务。任务 ID 只在其所属会话中有效。本机客户端能访问所有会话。

## 委派工具

- `delegate({tasks:[{task:'任务 A'},{task:'任务 B'}]})`：并行启动，立即返回 `{taskIds:[...]}`。
- `read_result({taskId:'...',resultId:'...'})`：仅在收到完成通知后，用通知中的随机 UUID 读取该任务结果。移除 `wait` 和批量 ID 参数，不提供轮询/等待入口；错配、跨会话或未完成均拒绝。重复读取保留结果，失败与取消也有可读结果。
- `append({taskId:'...',text:'补充指令',mode:'steer'})`：给运行中的子代理追加内容，默认 `steer`（下一安全点插话），可选 `followUp`（当前工作告一段落后接续）。回执只表示入队，不表示已执行；启动中、已结束或取消中的任务拒绝追加。

子任务结束后生成独立 `resultId`，先把结果和待通知状态落盘，再主动触达主代理。通知只带 taskId/resultId/status，不塞完整结果或子代理系统提示词。当前主代理还在运行时先保留通知，等该次运行结束后合并通知并启动新一轮；空闲时直接唤醒，不进入可撤回的用户队列。主代理收到通知再调用 read_result，不轮询。停止会话会暂停自动唤醒，下一条用户消息恢复；服务关闭不再唤醒。重启会补发未确认送达的通知（崩溃窗口可能重复，同一 resultId 可重复读取），不会重跑子任务；旧任务缺少凭证时在加载时补发凭证。通知状态表示通知轮已处理完，不保证模型一定读取了结果。

输入框「＋」上方显示当前会话进行中的子代理摘要：启动中/运行中每个一行，转圈图标与单行省略文本；点击或用 Enter / 空格激活后跳到会话内对应 `SUBAGENT` 卡片并聚焦，暂停自动跟随，不直接弹出详情。可继续点击卡片查看详情，或点「回到最新消息」恢复跟随。任务结束自动移除，无任务时隐藏，切换会话不混入其他会话任务。

无固定并发上限、任务超时、只读限制或结果截断。子 Agent 没有递归委派工具。并行修改同一文件可能冲突，应让主 Agent 分配不同文件，或使用不同工作目录/worktree。取消不回滚已发生的文件修改。主代理与子代理遇到模型限流、可恢复网络异常或意外中断时自动避让续跑，最多重试 30 次；间隔为 `3、3、3、6、6、12、24、48、96、192……秒`，48 秒之后持续翻倍，不封顶（后期可能等待很久）。Stop 会立即取消等待；凭证、权限、计费等永久错误不重试。重试保留已完成工具结果，不重新发送原始任务；正常结束不凭空判断“任务未完成”，仅对明确的可恢复失败重试。重试详情显示次数、错误和预计继续时间，成功后折叠，可手动展开；记录随会话保存，服务重启不会自动继续执行。

实现参考 [OpenAI Node SDK](https://github.com/openai/openai-node#retries)、[Anthropic TypeScript SDK](https://github.com/anthropics/anthropic-sdk-typescript#retries) 及已安装 Pi SDK 的错误分类/安全继续机制。禁用底层重复重试，由 Axiom 统一计数；采用上述指定时间表，不额外加入随机抖动。SDK 消息边界未保留原始 HTTP Retry-After 响应头，因此这里不宣称支持按该响应头调整等待。

## 模块边界

```text
main.js     配置与组装
server.js   HTTP / WebSocket / 鉴权
protocol.js 请求校验
sessions.js 主会话、订阅、快照、取消
  tools.js  委派、凭证读取、追加指令的参数和适配
  tasks.js  子任务状态、并行执行、结果
pi.js       Pi SDK 创建、事件适配与释放
compaction.js 后台摘要、检查点校验与安全轮次提交
capabilities.js 原生能力发现、内存配置、MCP 快照与选择加载
```

任务状态只归 tasks 管理，工具不保存另一份状态；传输层不直接调用 Pi SDK。采用原生 JavaScript ES modules 和 Node 测试工具，不增加编译步骤或工作流框架。

## 验证和运行边界

项目级 skill `codebase-map`（.pi/skills/codebase-map/）：多级索引快速定位代码与排障。`node .pi/skills/codebase-map/scripts/reindex.mjs` 重建 INDEX.md（模块总览→符号行号→协议/路由/元素常量）；knowledge.md 沉淀历史 bug，改代码后重建索引并追加记录。

```sh
npm test           # 含默认配置、浮层隔离/跳转、主子共享渲染、断线恢复及缓存回归
node tests/benchmark.js # CPU/DOM 微基准，不代表模型生成速度
node tests/conversation-preview.mjs # 127.0.0.1:4321，无模型/用户数据的会话 UI 样例
node tests/smoke.js  # 真实模型验证，会产生模型调用费用
```

默认新会话配置通过同目录临时文件原子替换保存，写入串行执行；配置损坏时启动报错，不静默重置。会话历史、配置和子任务结果落盘，进程重启后恢复，但不自动续跑。队列与未完成的流式片段仅在内存中，重启不恢复。会话需显式关闭以释放历史与结果；长期服务需监测内存。发送缓冲过大时断开慢客户端，重新 attach 获取快照；不静默丢正文。单条 WebSocket 输入上限 1 MiB，属于网络输入保护，不是任务数量限制。

当前为前台 Node 服务，不含操作系统开机自启或自动拉起配置。使用 SIGINT/SIGTERM 正常关闭时取消并清理所有会话；强杀进程没有完成清理的保证。

## 会话操作与断线恢复

- 左侧每条会话框内右侧提供中性色铅笔重命名、垃圾桶删除图标；无需切换会话即可操作。长标题使用省略号，图标保留固定空间，悬停可查看完整标题。删除确认默认聚焦取消，危险按钮及悬停均为红色；弹窗复用暗色边框与背景。
- WS 初次连接失败或断开后按 1、2、4、8、15 秒间隔自动重试，成功后重置；保留草稿并恢复会话快照。连接正常时不轮询，手动重试不创建并发连接。

内部子任务完成通知只用于唤醒主代理，不在会话正文显示；任务卡片与结果读取保持不变。
