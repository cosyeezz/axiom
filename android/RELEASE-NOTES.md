# Axiom Android 0.1.2 Preview（候选，尚未发布）

Android 独立客户端，内嵌 Tailscale tsnet；无需独立 Tailscale App，不占系统 VPN。电脑仍需运行 Axiom 和 Tailscale，并开启 Axiom 远程入口。

## 下载与安装

下载本页 **Axiom-Android.apk**，在 Android 8.0/API 26 或更新版本安装。包含 arm64-v8a 与 x86_64 原生库；32 位设备不支持。仅对你信任的下载来源批准安装，不需要关闭系统安全功能。

本版仍为预发布版，可使用同一正式签名覆盖安装 0.1.0/0.1.1。先在电脑确认远程访问可用，再在 APK 输入 `100.x.x.x:4319` 或完整 `.ts.net:4319` 地址，点击连接、使用系统浏览器完成官方 Tailscale 授权，回到应用。账号必须与电脑许可的个人账号一致；有设备审批时需管理员批准。

## 本版改进

- 默认沉浸式隐藏系统栏，边缘手势临时呼出；兼容Insets避让cutout和软键盘，不刷新已建立页面。最低版本仍为API26。
- 手机顶栏无框图标、单层更多与固定关闭入口；紧凑底栏SVG百分比，向上阅读才显示“回到最新”。长提示词折行，Todo固定标题和独立辅助滚动，更新重验已读范围、保留详情，读失败不伪装旧尾页为当前项。压缩应用后提示消失，历史仍可查看。

- 正常聊天移除原生常驻连接栏；连接设置收进网页「更多」和系统返回入口。查看设置或取消操作不重建页面；刷新、切换电脑、清登录需要确认。
- 手机正文保持 14px，行高由 1.8 收至 1.6；网页低频操作收进「更多」，保留桌面布局、关键操作、焦点与触控尺寸。
- 首屏网络/健康检查瞬时失败保留电脑目标，以有限退避重试；失败文档重建 WebView 隔离旧回调，Cookie 清除、写入与导航顺序串行。鉴权拒绝不自动解除。
- 电脑端共享网页传输新增握手期限、只读心跳、恢复无进展期限，以及受控前台/网络恢复。不重放结果未知的请求；重连等待期间的新草稿与阅读位置会保留，不自动刷新已建立工作台。
- 电脑端已保存的远程入口许可在 Tailscale 启动较晚时有界恢复；显式启用失败不留下后台开放许可。以上网页与电脑端修复需要同步更新电脑上的 Axiom，单独安装 APK 不能替换电脑服务。

## 功能与边界

- 节点身份在应用私有、禁备份目录保存，后续打开自动恢复。
- 网页与 WebSocket 使用固定目标、会话认证的应用内代理；不公开电脑服务端口。
- 图片由 Android 文档选择器选取；提供连接设置、确认刷新/切换电脑与清除本机登录。
- 不承诺锁屏后台永久在线，不含推送、原生下载管理或手机端 Agent。
- 本地代理端口变化时网页 localStorage 不保证保留；电脑端会话仍在，可重新选择。
- 没有预置入网密钥。清除本机登录不等于在 Tailscale 管理后台撤销设备。
- 保留 Tailscale 默认诊断日志上传及 tailnet 审计兼容性；本地状态/日志存于应用私有禁备份目录。

## 0.1.1 历史验证

[0.1.1候选 CI](https://github.com/cosyeezz/axiom/actions/runs/36615974900) 已通过 Go race、arm64-v8a/x86_64 AAR、APK 构建/lint、持久签名指纹核验、Android 11 x86_64 模拟器 **16 项（0 失败）**以及正式 release APK 实际安装。标签发布流水线再次执行相同门禁；不沿用 0.1.0 结果冒充本版通过。

集成后的隔离 Node 全量 **1049 项：1047 通过、2 项平台跳过、0 失败**；四套 Chromium 移动布局/桌面对照、焦点与 UI 回归通过。390px 同内容测得正文行高 25.2→22.4px、内容高度约 676→623px，网页顶栏 64→56px。模拟器确认正常态原生恢复栏隐藏、真实点击/系统返回打开设置、取消操作保留实例/草稿/滚动。自动首屏恢复使用受控探测结果与真实 loopback 文档，不等于真实 tailnet 恢复；本地代码与测试不承诺所有网络永久在线。

**这些不替代真实 tailnet 端到端验收。尚未代替用户完成本人账号授权、真机聊天/图片上传/锁屏恢复；Windows Pake/WebView2 睡眠唤醒与 iOS 浏览器锁屏/网络切换也未实测。** Windows 与 iOS 共享网页恢复层不等于平台实测通过。请先在可信环境试用；未测试项目不标为通过。
