# 行为保持型优化逐项答卷

日期：2026-09-23。审查基线：`947ce52`。参考《Axiom_行为保持型代码优化方案_2026-09-22》，以现有实现和行为契约为准，不以方案结论为准。

| 项目 | 决策与实际处理 |
| --- | --- |
| O-01 死状态/导入 | 当前基线已移除方案中的 nativeBusy 和未用导入，不重复修改；保留 native 结果兼容分支及旧历史读取能力。 |
| O-02 快照账单 | 快照账单复用已取得的 runtime，调用从三次降到两次；配置仍单独取得动态 runtime，不共享可变输出，不跨请求缓存。 |
| O-03 重试投影 | 主记录前缀计数替代每条重试从头扫描；总工作量随原历史、投影、重试数线性增长。保持负数归零、超界截断、非整数和未变对象身份。 |
| O-04 压缩局部索引 | beforeCommit 使用局部 Set；摘要与 checkpoint 的 manifest 每次只读取一次归档记录；覆盖哈希使用首匹配 Map，复用已查出的父摘要。保留原数组顺序、提示词、两次提交前检查、完整内容哈希与新鲜度检查。当前 raw-history 无方案中的大型 includes 查找；两种条目类型的 includes 不改。 |
| O-05 广播 | 广播只计算一次 UTF-8 字节数；私有发送函数复用结果，公开接口不变。逐客户端积压、关闭、失败和 FIFO 语义不变。 |
| O-06 归档哈希 | 本轮按具体 entry 配对哈希；私有写入函数复用，公开 record 仍自行计算。校验 Map 仍保持原最后值语义，写入仍按原顺序逐项处理。拒绝按 ID 传递哈希及公开可信哈希参数的初稿。磁盘空间检查仍在重复记录返回前；fsync、artifact 读取、barrier、故障锁定不变。 |
| O-07 局部 output 刷新 | 本次保留全量刷新。确有减少跨 output 扫描的机会，但须新增影响域收集、参数透传与全量/局部合并语义，并核实 toggle、快照重放、压缩挂载等入口；这不是消除既有重复实现，而是新增增量失效机制。本次不为此增加约30–50行状态调度逻辑。未声称其没有性能收益。 |
| O-08 活动计时集合 | 保留现状。工具状态入口集中，但另建活动集合仍需在结束、任务卸载、快照清空与恢复入口同步引用；会新增第二份状态及维护点。现有每秒扫描保留完整历史与原资格判断，不以任务status替换execution.endedAt。未进行性能基准，不宣称扫描成本可忽略。 |
| O-09 局部去重 | 两个同一同步判断内复用 Goal 快照；流式 relayout 复用 cap(all)。不跨 await 缓存，不改 Intl.Segmenter、不引入固定尾窗。 |
| O-10 注释/文档 | 修正 journal 缺失说明、Goal failure 字段说明、重试复杂度与错位的快照/压缩展开注释。旧OP文档和分页性能报告标为历史证据；不改原测量数值。纯署名前缀无运行收益，不全库机械改名。 |
| O-11 职责抽取 | 历史纯投影、调用组展示并无多份同职责实现，不机械拆文件。过程记录确有路径/字段列表重复，但同步冷快照、异步单条读取、活动记录克隆和原子写语义不同；为几个表达式增加读写模块接口不符合本轮净精简方向，保持现状。 |

## 验证原则

- 基线全量测试通过后才修改。
- 重试私有纯函数使用旧算法进行500组固定随机差分，检查内容和对象身份。
- 账单测试检查 runtime 调用次数、主子账单一致性及输出对象隔离。
- 传输补测中文/emoji、等于和超过字节阈值、except、关闭客户端、异步发送失败。
- 归档补测重复ID异内容的部分写入与冲突、同内容幂等、删除来源及公开接口不能绕过哈希校验。
- 运行压缩、历史投影、旧归档读取、journal、ownership、Goal、流式字素与最终全量回归；不把扫描次数减少宣称为等比例端到端提速。

本轮核心收益是减少重复计算和查找，不引入全局缓存、公开接口参数、持久化格式变化或新的边界策略。必要的局部索引会增加少量声明；不以压缩行数牺牲语义清晰度。
